# PLAY11 · 미니게임 아케이드

별도 빌드 도구 없이 실행할 수 있는 모바일 우선 정적 웹앱입니다. `index.html`을 브라우저로 열거나, 프로젝트 폴더에서 `python3 -m http.server 4173`을 실행한 뒤 `http://localhost:4173`로 접속하세요.

스마트폰에서 사용할 때는 HTTPS 주소로 접속하면 Chrome의 `홈 화면에 추가` 또는 앱 설치 안내가 표시됩니다. 홈 화면에 설치한 뒤에는 전체 화면 앱처럼 실행되고, 서비스 워커가 등록되어 다음 실행부터는 네트워크가 불안정해도 기본 게임을 불러올 수 있습니다. 음성 인식은 Chrome 계열 브라우저에서 권장됩니다.

공개 배포본: https://goodmondaysljh-cyber.github.io/play11-site/

끝말잇기 배틀은 브라우저가 Web Speech API를 지원할 때 마이크 입력을 사용할 수 있고, 지원하지 않으면 직접 입력으로 플레이할 수 있습니다. 테트리스와 리듬 게임은 키보드 보조 입력도 지원하며, 나머지 게임은 터치·포인터 중심으로 설계했습니다.

`app.js`에 60개국 수도·국기 데이터, 초성 단어, 자동차 엠블럼·모델 데이터가 포함되어 있고, 최고점은 브라우저의 localStorage에 저장됩니다.
